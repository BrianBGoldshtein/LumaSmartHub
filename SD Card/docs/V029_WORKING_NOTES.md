## Crucial actual-engine findings

The worker protocol is now version two: `KWS02\n`, followed by a 17-byte status/first-phone-start/last-phone-start reply (`>Bdd`). A final phone timestamp is a **start**, not a word end. Do not add an arbitrary name-duration trim: it erased joined command verbs/negation. A fixed 80ms overlap margin preserves a measured timer verb whose ASR start preceded the phonetic timestamp by 50ms; overlapping negation vetoes rather than silently rewriting an action.

An early replay using Vosk `Reset` appeared correct in mocks but failed 14/15 synthetic positive wakes with invalid word alignment. Actual Vosk retains cumulative timing across Reset; fresh `KaldiRecognizer` instances sharing the loaded Model now start each timed replay at zero. Keep `report-timed-command-original-20261005.json` as failed evidence, not hidden history. [Vosk recognizer implementation](https://raw.githubusercontent.com/alphacep/vosk-api/master/src/recognizer.cc) supports this correction.

The constrained grammar cannot substitute its prefix judgment for unrestricted speech: it invented `hey` for a real `okay` hesitation. Only the independent timed prefix is judged; the command grammar still provides a second interpretation for command/slot safeguards. No fuzzy name aliases were added. Legitimate `switch to the wooden/cabin/arcade theme` grammar phrases fix a separate ordinary command-vocabulary hole.
